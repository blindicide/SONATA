# Changelog

## 0.1.1 — Overture

- Scan formats on adding a source; show real resolution choices per video and select the highest by default.
- Default to MP4 and prefer source AAC audio, retaining video quality and metadata during compatibility finalization.
- Add a separate FFmpeg window for inspection, conversion/remuxing, audio extraction, trimming, resizing, normalization, metadata, subtitles, thumbnails and advanced arguments.
- Persist scanned choices, migrate existing queues, and apply playlist transfer actions to children.
- Publish only four application packages and one checksum file.

## 0.1.0 — Overture

- Initial Qt desktop application for Windows 10/11 and Linux x86-64.
- Persistent concurrent transfer queue, playlist/channel expansion, local library and collections.
- Format/codec selection, FFmpeg audio extraction/remuxing, subtitles, metadata and thumbnails.
- Local TAR/TAR.GZ exports with checksums and a manifest.
- Independent verified yt-dlp updater and bundled fallback.
- English/Russian interface, light/dark themes, portable/installer/Linux build recipes.
