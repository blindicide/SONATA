# Changelog

## 0.1.0 — Overture

- Initial Qt desktop application for Windows 10/11 and Linux x86-64.
- Persistent concurrent transfer queue, playlist/channel expansion, local library and collections.
- Format/codec selection, FFmpeg audio extraction/remuxing, subtitles, metadata and thumbnails.
- Local TAR/TAR.GZ exports with checksums and a manifest.
- Independent verified yt-dlp updater and bundled fallback.
- English/Russian interface, light/dark themes, portable/installer/Linux build recipes.
