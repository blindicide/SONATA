## Changes

- **Resolutions belong to each video.** Adding a URL scans its available formats. Each queue entry has a resolution dropdown and defaults to its highest available resolution, including nonstandard sizes. Playlists expand and scan their entries individually.
- **MP4 is the default.** AAC source audio is preferred for MP4, with H.264 preferred when resolutions tie. If an MP4 needs Opus audio converted for compatibility, video is kept without re-encoding.
- **Metadata and stream information are preserved.** MP4 output retains tags and chapters, uses a finalized fast-start index, and is validated with FFprobe. The reported MKV example contained its metadata; Windows Explorer did not display its technical fields. A matching MP4/AAC test copy exposes them correctly through Windows' property reader.
- **Tools → FFmpeg tools** opens a separate window for file inspection, remuxing, video/audio conversion, trimming, resizing, audio normalization, metadata editing, subtitle embedding/extraction, thumbnail extraction, and extra output arguments. Processing has progress and cancellation. Input files are kept; results use a separate output file.
- Existing libraries and queues are migrated without deleting history or media. New downloads use the new defaults; existing queued jobs retain their saved options.

Source scanning starts when a URL is added. Media transfers still require **Start / Resume**. Pause and start actions on a playlist include its child jobs.

English/Russian localization and light/dark themes are supported in the new window. Binaries remain unsigned; source formats and availability depend on the service.

[SHA256SUMS](https://github.com/blindicide/SONATA/releases/download/v0.1.1/SHA256SUMS) covers the four application packages. GitHub's automatic source-code archives are for development, not running the application.
