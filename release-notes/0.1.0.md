SONATA — a local multimedia downloader and archival manager.

## Windows 10 / 11

### [Download the Windows installer (.exe)](https://github.com/blindicide/SONATA/releases/download/v0.1.0/SONATA-0.1.0-windows-x64-setup.exe)

This is the recommended download for Windows. Run it to install SONATA.

Prefer no installation? [Download the Windows portable ZIP](https://github.com/blindicide/SONATA/releases/download/v0.1.0/SONATA-0.1.0-windows-x64-portable.zip), extract the entire folder, and run `SONATA.exe`.

## Linux x86-64

[Debian / Ubuntu package (.deb)](https://github.com/blindicide/SONATA/releases/download/v0.1.0/sonata-archiver_0.1.0_amd64.deb) · [Linux portable archive (.tar.gz)](https://github.com/blindicide/SONATA/releases/download/v0.1.0/SONATA-0.1.0-linux-x86_64.tar.gz)

Linux builds use Ubuntu 22.04 as their baseline and require standard desktop graphics libraries.

Application runtimes, yt-dlp, FFmpeg, FFprobe and Deno are bundled. No account or separate runtime installation is required to run SONATA. Some media services restrict anonymous access.

## Included

- Compact Qt desktop interface with real menus, toolbars and sortable tables.
- English/Russian localization and light/dark themes.
- Video, audio, playlists and channel downloads; resolution ceilings up to 8K where offered by the source.
- Codec/container selection, subtitles, metadata, thumbnails, concurrent transfers, rate limits and retries.
- Pause/resume where the source supports it; persistent queue recovery and SQLite duplicate prevention.
- Searchable local library, named collections and TAR/TAR.GZ exports with checksum manifests.
- Independently updated yt-dlp with checksum verification and a bundled fallback.
- No telemetry or SONATA cloud service.

## Validation

The application passed **32 automated tests on Windows and Ubuntu**, including real FFmpeg conversion and byte-range pause/resume. Standalone Windows startup, live anonymous YouTube extraction and the independent updater were also checked. [Verified build](https://github.com/blindicide/SONATA/actions/runs/41316533412).

This is the initial release. Binaries are unsigned; source/extractor availability and transfer resume depend on the service. Windows 8.1, 32-bit systems, ARM and macOS are outside this release's targets.
